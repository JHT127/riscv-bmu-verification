# Bug Reports

[BMU_Bug_Log.md](BMU_Bug_Log.md) is the canonical bug record. Each active finding has an isolated `bmu_bug_NNN_test` and retained [runtime evidence](../../results/bugs).

- **Open — runtime confirmed:** a specification mismatch was observed in simulation.
- **Withdrawn:** the original claim was unsupported by the evidence.
- **Fixed:** a revised DUT passes the reproducer and relevant regression.

Assumption-dependent behavior remains labeled. A passing coverage percentage does not close a bug, and the verification team does not edit the delivered DUT to make a reproducer pass.
