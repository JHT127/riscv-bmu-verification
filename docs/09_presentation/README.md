# Presentation

This folder contains the final presentation exports for the BMU verification project:

- `BMU_presentation.pdf` — portable presentation for review and submission.
- `BMU_presentation.pptx` — editable presentation source.

The deck presents the specification-driven verification flow, UVM environment, sequence-item lifecycle, assertions, coverage, regression evidence, and open DUT findings. The measured baseline remains the original delivered RTL; the presentation does not claim DUT sign-off.
